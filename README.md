## Recursos Principais

- **Busca Instantânea & Filtros para Celular:** Localização rápida de ports nativos, source ports e recompilações para Android e iOS, com filtros dedicados por sistema operacional móvel e console original.
- **Identificação de Controles:** Destaque para compatibilidade com controles táteis na tela (touchscreen) e suporte a gamepads Bluetooth externos.
- **Suporte aos Pacotes Mobile:** Indicação do formato de instalação (APK, IPA, Sideload, Source Port).
- **Operação 100% Local / Offline:** Arquitetura desacoplada de serviços externos com carregamento rápido e armazenamento local de sugestões.
- **Design Moderno no Padrão Verde SSLabs:** Interface ergonômica com tema escuro padrão, alternância claro/escuro e layout responsivo.
